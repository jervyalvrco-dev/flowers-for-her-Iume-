# Virtual Flowers for Lume 🌸

A romantic, interactive web project featuring blooming pastel flowers, a custom message, and a featured photograph.

## Features
- **Animated Blooms**: Flowers grow and open using CSS keyframes.
- **Custom Message**: A timed "popping" message appears after the garden blooms.
- **Responsive Photo**: Displays a special photo with a soft glow effect.

## Tech Stack
- HTML5, CSS3 (Custom Variables & Animations), Vanilla JavaScript
